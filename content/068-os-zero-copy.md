## 说人话
把文件发到网络时，传统路径可能先搬到应用内存，再搬回内核。零拷贝想省掉这些绕路，但不代表机器完全不搬数据。

## 先这样回答
零拷贝通常指减少用户态与内核态之间的数据复制，或减少 CPU 参与的数据搬运。sendfile 等机制可以在合适场景直接连接内核中的输入与输出路径。

## 把原理拆开
实际收益取决于操作系统、文件类型、网络协议和是否需要应用层修改数据。TLS、压缩或格式转换可能改变可用路径，不能只凭 API 名字推断没有复制。

## 继续追问
为什么需要修改文件内容时方案会不同？mmap 加 write 和 sendfile 分别省了什么？

## 容易说错的地方
> 零拷贝不等于零系统调用、零 DMA 或任何场景都更快。
