## 说人话
传进方法的是变量值的副本。拿着同一把钥匙可以改房间里的东西，但换掉自己手里的钥匙不会替别人换钥匙。

## 先这样回答
Java 的参数传递是值传递。基本类型复制它的值；引用类型复制引用值。方法内的参数和外部变量可以指向同一个对象，因此能通过参数修改对象，但给参数重新赋值不会替换外部变量。

## 把原理拆开
```java
static void update(User user) {
    user.name = "new"; // 修改同一个对象
    user = new User(); // 只替换方法内参数的引用
}
```
调用后，原 User 对象的 name 被修改，但调用方的引用不会因为第二行而指向新 User。

## 继续追问
- 方法内能不能交换调用方的两个对象变量？——仅交换参数不行，可以返回交换后的结果，或修改调用方提供的可变容器。
- 传入 String 后为什么看起来改不了？——String 不可变，对它重新赋值只是改变局部引用。

## 容易说错的地方
> 能修改传入对象，不等于能修改调用方保存该对象的变量。
