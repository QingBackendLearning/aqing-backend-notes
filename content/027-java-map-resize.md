## 说人话
格子变多了，按哈希值算出来的格子位置也可能变。扩容还要搬数据，所以并非免费。

## 先这样回答
容量和负载因子影响何时扩容。映射位置依赖容量；扩容后条目需要分配到新的桶结构。JDK 的具体搬迁算法是实现细节，不能把 API 契约和源码混写。

## 把原理拆开
预估键数量时，可以合理设置初始容量，减少反复扩容；但过大的容量也会增加空间和遍历成本。

## 继续追问
负载因子调得越小越好？——碰撞和空间之间存在取舍，应根据负载测量。

## 容易说错的地方
> 扩容不是只分配一个更大数组、把旧数组原样放进去。
